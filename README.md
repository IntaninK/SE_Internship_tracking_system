# SE_Internship_tracking_system
ระบบติดตามการเตรียมความพร้อมเข้าฝึกงานของนิสิตSE

คือเว็บไซต์ฐานข้อมูล ที่จัดการข้อมูลการเตรียมความพร้อมฝึกงานของนิสิตสาขาวิศวะกรรมซอฟร์แวร์ คณะเทคโนโลยีสารสนเทศและการสื่อสาร
